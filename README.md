# RIGFORGE — конфигуратор сборки ПК

Анимационный лендинг-конфигуратор: подбор комплектующих с реалистичной проверкой
совместимости (сокеты, чипсеты, форм-факторы, TDP, питание) плюс ветка апгрейда ноутбука.
Чистый HTML/CSS/JS без зависимостей и сборки.

## Запуск локально

```bash
python3 -m http.server 8791
# открыть http://127.0.0.1:8791/
```

Любой статический сервер подойдёт (`npx serve`, nginx и т.п.).

## Возможности

- **Сборка ПК** — 9 категорий, 91 модель, пресеты «Офис / Игры 1080 / 1440 / Тяжёлые»,
  live-совместимость карточек, сводка с вердиктом, расчёт рекомендуемого блока питания.
- **Апгрейд ноутбука** — 12 моделей, замена RAM/SSD/HDD/Wi-Fi, проверка ограничений
  (паяная память, один слот, поддерживаемые носители).
- **Каталог** — фильтры по категориям и цены в ₽.
- **Обратимая ссылка** — состояние сборки кодируется в `#b=`.
- Доступность: `prefers-reduced-motion`, семантика, клавиатурная навигация.

## Структура

```
index.html        — разметка
css/style.css     — дизайн-система и анимации
js/data-pc.js     — каталог ПК-компонентов (CATALOG)
js/data-laptop.js — ноутбуки и запчасти (LAPTOPS)
js/engine.js      — правила совместимости (analyze / analyzeLaptop)
js/art.js         — SVG-иллюстрации и иконки
js/app.js         — состояние, рендер, события, анимации
```
