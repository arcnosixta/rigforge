# RIGFORGE — конфигуратор сборки ПК

Анимационный лендинг-конфигуратор: подбор комплектующих с проверками совместимости
(сокеты, типы памяти, форм-факторы, габариты, интерфейсы накопителей и питание), плюс
ветка апгрейда ноутбука. Чистый HTML/CSS/JS без сборки и сторонних runtime-библиотек.

## Запуск локально

```bash
python3 -m http.server 8791
# открыть http://127.0.0.1:8791/
```

Любой статический сервер подойдёт (`npx serve`, nginx и т.п.).

## Возможности

- **Сборка ПК** — 9 категорий, число моделей берётся из каталога, пресеты и бюджетные
  сборки от офиса до игрового ПК, live-совместимость карточек, сводка и расчёт
  рекомендуемой мощности блока питания.
- **Апгрейд ноутбука** — 12 моделей, замена RAM/SSD/HDD/Wi-Fi, проверка ограничений
  (паяная память, один слот, поддерживаемые носители).
- **Валюты** — отображение цен в RUB/USD/KZT по ежедневному курсу ExchangeRate-API.
  Последний успешный курс хранится в браузере; при недоступности API отображаются дата
  курса из кэша или понятное сообщение о недоступности конвертации.
- **Каталог** — фильтры по категориям и цены в выбранной валюте.
- **Фото товаров** — карточки принимают HTTPS-фото конкретной модели через `photoUrl`,
  `photoSource` и `photoSourceUrl`; при недоступном изображении остаётся SVG-иллюстрация.
  Проверяйте права/условия использования и точность модели перед добавлением изображения.
- **Обратимая ссылка** — состояние сборки кодируется в `#b=`.
- Доступность: `prefers-reduced-motion`, семантика, клавиатурная навигация.

## Данные и проверки

Цены ориентировочные и заданы в рублях. Пересчёт в другие валюты — только для отображения,
это не локальные цены и не платёжная конвертация. Курс USD/KZT берётся из
[ExchangeRate-API](https://www.exchangerate-api.com/) с базой RUB и кэшируется в браузере.

Проверки движка — эвристики по заполненным данным, а не гарантия запуска или замена
спецификаций производителя. В частности, опубликованный TDP кулера не является
стандартизованной мерой тепловой нагрузки, а рекомендации по мощности — оценка с запасом.
Совместимость конкретного BIOS, ревизии, посадочных мест, кабелей и ограничений корпуса
может требовать ручной проверки.

Бюджеты готовых сборок заданы в RUB по сумме цен каталога. Это примеры, не котировки магазина:
состав и итоговую стоимость проверяйте перед покупкой.

## Проверка

Откройте `tests/engine.test.html` в браузере или через локальный сервер, чтобы запустить
проверки сокетов, типа памяти, габаритов, питания, ноутбуков и готовых бюджетных сборок.

## Структура

```
index.html        — разметка
css/style.css     — дизайн-система и анимации
js/data-pc.js     — каталог ПК-компонентов (CATALOG)
js/data-laptop.js — ноутбуки и запчасти (LAPTOPS)
js/engine.js      — правила совместимости (analyze / analyzeLaptop)
js/art.js         — SVG-иллюстрации и иконки
js/app.js         — состояние, рендер, события, анимации
tests/engine.test.html — браузерные тесты движка и бюджетных сборок
```
